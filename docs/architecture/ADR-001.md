# ADR-001 — Monólito modular .NET com API, BFF e worker separados

Status: aceita para S00. Data: 2026-09-08.

## Contexto e decisão

A plataforma começa como monólito modular em .NET 10 LTS. Domain não conhece infraestrutura; Application contém casos de uso/ports; Contracts contém DTOs HTTP; Infrastructure implementa Dapper/Npgsql; Api e Worker são processos separáveis; Web é MVC/BFF sem acesso direto ao banco. PostgreSQL 18 guarda identidade, metadados, auditoria e inventário inicial.

O desenho reduz complexidade operacional inicial e preserva fronteiras para separar cargas quando métricas reais justificarem. Tenant será aplicado na identidade, repositórios, transação e RLS; identificadores opacos não substituem autorização.

## Decisões de segurança

- Web usa cookie protegido, `HttpOnly`, `Secure`, `SameSite=Lax` e antiforgery; JWT não é exposto ao JavaScript.
- JWT HS256 curto inclui `sub`, `jti`, sessão e security version; cada requisição autenticada revalida a sessão no servidor.
- A role de aplicação não é dona, superusuária ou `BYPASSRLS`; ausência de contexto tenant produz negação nas políticas S00.
- Segredos de Development são aleatórios e ficam em `%LOCALAPPDATA%`, nunca em appsettings versionado.
- Conteúdo de contratos exigirá sessão de suporte específica em S01; privilégio global genérico não autoriza abertura.
